# 功能安全 / 预期功能安全 / AI 安全资料包

这个资料包面向智能驾驶工程实践，按主题整理了常用标准、法规与公开技术资料。

## 目录

- `fusa/`：功能安全（FuSa）核心标准与方法
- `sotif/`：预期功能安全（SOTIF）核心标准与方法
- `ai_safety/`：AI 安全与模型风险管理
- `ads_regulation/`：智能驾驶法规与行业指南
- `must_read_by_phase.md`：按项目阶段的必须先读清单
- `integrated_fusa_sotif_ai_process_template.md`：一体化安全开发流程模板

## 使用建议

1. 先读 `fusa/reading_guide.md` 与 `sotif/reading_guide.md`，建立术语与流程框架。
2. 再读 `ai_safety/reading_guide.md`，补齐数据、模型与运行监控安全。
3. 最后结合 `ads_regulation/reading_guide.md`，完成法规和认证映射。

## 说明

- 其中部分标准文本为付费标准，本文档提供官方入口与工程解读要点。
- 建议在项目中建立“标准条款 -> 安全需求 -> 证据工件”的双向追踪矩阵。
