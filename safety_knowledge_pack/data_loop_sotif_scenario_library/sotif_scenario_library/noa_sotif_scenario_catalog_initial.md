# 城市NOA/高速NOA 的 SOTIF 场景库初始目录（v1.0）

用途：作为 SOTIF 场景库的启动版本，支持从“功能场景 -> 逻辑场景 -> 具体测试用例”逐步落地。

## 1. 目录结构建议

- `C-NOA-*`：城市 NOA 场景
- `H-NOA-*`：高速 NOA 场景
- 每个场景条目至少包含：
  - 场景ID
  - 场景名称
  - ODD 边界
  - 关键触发条件
  - 潜在功能不足（SOTIF 风险点）
  - 风险等级（S1-S4 建议）
  - 优先级（P0/P1/P2）
  - 覆盖状态（未覆盖/仿真/封闭场地/实车/回归）

## 2. 城市 NOA 初始目录（功能场景层）

- `C-NOA-001` 无保护左转会车冲突
- `C-NOA-002` 路口右转礼让行人与非机动车
- `C-NOA-003` 施工区临时改道与锥桶收敛
- `C-NOA-004` 路边违停车辆绕行后回归
- `C-NOA-005` 鬼探头（静止遮挡后横穿行人）
- `C-NOA-006` 公交站进出站与侧向切入
- `C-NOA-007` 环岛进入/让行/驶出
- `C-NOA-008` 复杂路口多目标优先级冲突
- `C-NOA-009` 雨夜反光导致车道线识别不稳定
- `C-NOA-010` 城市高架匝道分流误导

## 3. 高速 NOA 初始目录（功能场景层）

- `H-NOA-001` 前车急减速（非AEB极限制动）
- `H-NOA-002` 邻道车辆强插入（小 TTC）
- `H-NOA-003` 大车遮挡后前方静止障碍暴露
- `H-NOA-004` 匝道汇入主路密集交互
- `H-NOA-005` 主路分流口（幽灵分叉）路径选择
- `H-NOA-006` 弯道+雨天+积水导致感知退化
- `H-NOA-007` 收费站前后标线与拓扑突变
- `H-NOA-008` 隧道进出明暗突变与目标丢失
- `H-NOA-009` 异形障碍物（散落物/轮胎）规避
- `H-NOA-010` 低速拥堵跟驰与频繁切入

## 4. 逻辑场景参数模板（每个场景都应参数化）

- 道路参数：曲率、坡度、车道数、限速、出入口密度
- 交通参数：流量、重车比例、切入率、目标速度分布
- 环境参数：天气、光照、能见度、路面附着系数
- 感知参数：遮挡率、有效探测距离、误检/漏检率
- 规划控制参数：期望时距、最大横向加速度、舒适约束
- 评价参数：TTC、THW、最小间距、接管需求时间

## 5. SOTIF 风险标签建议

- `INSUFF-PERCEPTION` 感知充分性不足
- `INSUFF-PREDICTION` 预测充分性不足
- `INSUFF-PLANNING` 规划策略充分性不足
- `INSUFF-HMI` 交互/接管提示充分性不足
- `TRIGGER-ENV` 环境触发（雨雾逆光等）
- `TRIGGER-TRAFFIC` 交通触发（强交互、高密度）
- `TRIGGER-RARE` 稀有触发（长尾场景）

## 6. 覆盖与入库门槛（建议）

- P0 场景：必须具备仿真 + 封闭场地 + 实车证据，且纳入每版回归
- P1 场景：至少仿真 + 其一实测证据，双版本内纳入回归
- P2 场景：完成逻辑场景定义并排入季度扩展计划

## 7. 版本管理建议

- 版本号：`catalog-major.minor.patch`
- 每次变更必须记录：新增/删除/合并原因，风险影响，回归影响
- 与数据闭环联动：新触发事件在 2 周内完成“候选 -> 评审 -> 入库/拒绝”

## 8. 配套文件

- `noa_sotif_catalog_seed.csv`：场景种子目录（可导入工具）
- `noa_sotif_logical_params_template.csv`：逻辑场景参数模板
