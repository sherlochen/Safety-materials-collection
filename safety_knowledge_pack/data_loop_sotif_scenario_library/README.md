# 智驾数据闭环与 SOTIF 场景库专题资料

本专题聚焦两件事：
- 如何建设可持续演进的智驾数据闭环（Data Loop）
- 如何建设满足 SOTIF 目标的场景库（Scenario Library）

## 目录

- `sotif_scenario_library/sotif_scenario_library_knowledge_map.md`

## 推荐阅读顺序

1. 先看 `data_loop_knowledge_map.md`（组织流程和闭环指标）
2. 再看 `sotif_scenario_library_knowledge_map.md`（场景体系和验证）
3. 然后看 `public_datasets_and_tools.md`（可落地工具与数据）
4. 最后按 `implementation_roadmap_template.md` 执行建设
