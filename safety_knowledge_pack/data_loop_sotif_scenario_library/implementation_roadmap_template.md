# 数据闭环与 SOTIF 场景库建设路线图模板（12个月）

## 阶段 1（M1-M2）：基线建立

目标：
- 完成组织分工、标准基线、数据治理边界定义。

关键动作：
- 定义事件分类体系（感知/预测/规划/控制/系统）
- 定义 ODD 与风险分级规则
- 定义场景三层模型（功能/逻辑/具体）

交付物：
- 数据闭环流程图 v1
- 场景库元数据规范 v1
- 风险优先级矩阵 v1

## 阶段 2（M3-M5）：闭环流水线打通

目标：
- 打通“事件发现 -> 样本生产 -> 训练回归 -> 发布门禁”。

关键动作：
- 建设自动事件挖掘与回流机制
- 建设样本生产与标注质检流程
- 建立高风险场景回归池

交付物：
- 周期化闭环报表
- 场景入库与出库准则
- 回归门禁策略（Go/No-Go）

## 阶段 3（M6-M9）：SOTIF 深化与未知场景发现

目标：
- 提升未知危险场景发现能力，形成可量化评估。

关键动作：
- 基于聚类/异常检测建立 corner case 挖掘
- 引入生成式场景扩展（逻辑到具体）
- 建立未知场景发现效率指标

交付物：
- SOTIF 高风险场景池 v2
- 未知场景发现报告（月度）
- 场景覆盖率看板（按 ODD 维度）

## 阶段 4（M10-M12）：安全论证与规模化运营

目标：
- 将闭环结果纳入 Safety Case，支持发布与监管审查。

关键动作：
- 建立条款->需求->测试->证据追踪矩阵
- 固化 OTA 安全门禁和回滚机制
- 形成跨版本可比安全指标体系

交付物：
- 一体化 Safety Evidence Pack
- 发布评审模板与审计包
- 年度改进路线图

## 建议度量（全程跟踪）

- 事件到修复周期（天）
- 高风险场景通过率
- 回归失败率
- ODD 外触发率
- 接管率与严重事件率
